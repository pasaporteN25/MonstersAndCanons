# M30 · Reflejos programáticos
Captura real1920×1080 de las nueve torres, filas niveles1/2/3. Usa datos y escenas de producción. Shader aditivo sobre reflejos existentes, con color por familia y pulso por tiempo físico. Sigue ocho vistas y retroceso; se apaga al aturdir. No se rediseñaron sombras ni se generaron nuevas animaciones de monstruos.

Ejecutar: `godot --path . --resolution 1920x1080 art/redesign-m30/capture.tscn`.
