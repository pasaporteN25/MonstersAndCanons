# M35 · Panel de torre

Muestras reales de Godot: niveles1–3, sin oro, aturdimiento, texto largo/foco e Hielo con sinergias. El panel conserva270×356 píxeles lógicos; contenido extenso desplazable y acciones fijas. El texto de aturdimiento se muestra en una fila independiente para no perderlo al truncar un nombre largo.

Reproducir desde PowerShell con APPDATA dentro de `build/t180-user` y `godot --path . res://art/redesign-m35/capture.tscn`. Las muestras usan guardado de prueba. La integración no cambia datos de combate ni sombras. Sin prueba física en Android ni Linux.
