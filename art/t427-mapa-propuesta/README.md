# T427 · Propuesta del mapa planetario

La muestra está dibujada para un viewport desktop de 1280×720. `mapa.svg` es la fuente editable; `captura_1280x720.png` es su render de revisión a tamaño completo.

El estado ilustrativo representa una campaña de ejemplo: zona 1 tomada con tres estrellas, zona 2 con presencia rebelde y dos estrellas, zona 3 desbloqueada y sin récord, y las zonas 4–15 bloqueadas. El aterrizaje tiene un icono propio. La leyenda combina pictogramas, texto y color para que los estados no dependan solo del color.

**Procedencia:** dibujo vectorial creado para esta propuesta, usando el marco oscuro, el acento bronce y el lenguaje de contorno del juego como referencia (`specs/05-guia-de-arte.md`, `art/redesign-m33/level_select.png`). Sin assets raster externos ni fuentes externas. El PNG de revisión se renderizó desde el SVG con librsvg; el archivo SVG ocupa menos de 20 KB.

Es una maqueta artística: no lee un guardado, no contiene interacción, no define el arte final ni se integra a escenas o lógica. El PNG pesa aproximadamente 240 KB; no se propone incluirlo en el producto. La integración y cualquier asset final esperan aprobación de Lucas.
