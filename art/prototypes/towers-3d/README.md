# Pruebas de volumen para torres

Selección de Lucas: `b_base_1.svg` y `b_base_3.svg` están aplicadas a las bases de madera y oro. `c_turret_cannon.svg` está aplicada al cañón. Los demás SVG de esta carpeta son bocetos comparativos; la opción C del hielo sigue pendiente de elección.
